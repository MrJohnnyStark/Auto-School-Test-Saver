## 🇷🇺 Русская версия

### 📖 Описание

**Auto School Test Saver** — это расширение для браузера Chrome, которое позволяет сохранять результаты тестов с платформы [auto-test.online](https://auto-test.online/). Идеальное решение для преподавателей и учеников автошкол, которые хотят сохранять и архивировать результаты экзаменационных тестов вместе с вопросами и ответами.

<img src="https://github.com/user-attachments/assets/3d30bc0b-7a29-45a8-b468-2eb9d70028d6" width="500" alt="Скриншот расширения">

### ✨ Основные возможности

- 💾 **Сохранение результатов** — Автоматическое сохранение результатов тестов в HTML формате
- 📝 **Полная информация** — Сохранение вопросов, ответов и изображений из тестов
- 👨‍🎓 **Данные ученика** — Указание имени ученика, даты и группы для организации файлов
- 🎯 **Удобная организация** — Все данные сохраняются в структурированном и читаемом виде
- ⚡ **Простота использования** — Интуитивный интерфейс с минимальными настройками

### 🚀 Установка

1. **Скачайте расширение:**
   - Клонируйте репозиторий или скачайте ZIP-архив:
     ```bash
     git clone https://github.com/AristarhUcolov/Auto-School-Test-Saver.git
     ```
   - Или нажмите `Code` → `Download ZIP` и распакуйте архив

2. **Установите в Chrome:**
   - Откройте Chrome и перейдите на страницу `chrome://extensions/`
   - Включите **Режим разработчика** (переключатель в правом верхнем углу)
   - Нажмите **Загрузить распакованное расширение**
   - Выберите папку с распакованным расширением

3. **Готово!** Иконка расширения появится на панели инструментов браузера

### 📋 Использование

1. Откройте страницу с результатами теста на [auto-test.online](https://auto-test.online/)
2. Нажмите на иконку расширения **Auto School Test Saver** на панели инструментов
3. Заполните форму:
   - **Имя и Фамилия Ученика** — ФИО тестируемого
   - **Число** — Дата прохождения теста
   - **Группа** — Номер или название группы
4. Нажмите кнопку **Сохранить**
5. Результаты автоматически сохранятся в HTML-файл на ваш компьютер

## 🇬🇧 English Version

### 📖 Description

**Auto School Test Saver** is a Chrome browser extension that allows you to save test results from the [auto-test.online](https://auto-test.online/) platform. A perfect solution for driving school instructors and students who want to save and archive exam test results along with questions and answers.

<img src="https://github.com/user-attachments/assets/3d30bc0b-7a29-45a8-b468-2eb9d70028d6" width="500" alt="Extension Screenshot">

### ✨ Key Features

- 💾 **Save Results** — Automatically save test results in HTML format
- 📝 **Complete Information** — Save questions, answers, and images from tests
- 👨‍🎓 **Student Data** — Specify student name, date, and group for file organization
- 🎯 **Convenient Organization** — All data is saved in a structured and readable format
- ⚡ **Easy to Use** — Intuitive interface with minimal settings

### 🚀 Installation

1. **Download the extension:**
   - Clone the repository or download the ZIP archive:
     ```bash
     git clone https://github.com/AristarhUcolov/Auto-School-Test-Saver.git
     ```
   - Or click `Code` → `Download ZIP` and extract the archive

2. **Install in Chrome:**
   - Open Chrome and navigate to `chrome://extensions/`
   - Enable **Developer mode** (toggle in the top right corner)
   - Click **Load unpacked**
   - Select the folder with the extracted extension

3. **Done!** The extension icon will appear in your browser toolbar

### 📋 Usage

1. Open the test results page on [auto-test.online](https://auto-test.online/)
2. Click on the **Auto School Test Saver** extension icon in the toolbar
3. Fill out the form:
   - **Student Name** — Full name of the test taker
   - **Date** — Test completion date
   - **Group** — Group number or name
4. Click the **Save** button
5. Results will be automatically saved to an HTML file on your computer
